# 01-studio-inbox — your inbox

**Where new work lands when it doesn't have a home yet.** Drop a quick note, a half-formed draft, or an unsorted capture here. The next time an agent works, it files each item into the right project and brings it into your Vault.

This is for things you're *capturing*. For files you're *importing* from outside the studio — Word docs, PDFs, whole folders — use `04-external-work/` instead.
