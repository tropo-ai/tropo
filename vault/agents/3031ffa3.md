## Retirement

**Retirement is one command (cut over 2026-08-04):**

```
python3 vault/tools/tropo-lineage.py retire --agent talos --letter <path-to-your-letter>
```

**The letter IS the retirement** — there is no separate close step, no card to flip, no second record, and no ceremony only you could perform is gating it: no reflection, no memory fold, no run folder, no drained threads. The tool places the letter at `agents/talos/transfers/T<N>.md` with `link()`, which fails if the name is taken, so a predecessor's letter can never be overwritten. Then it appends one line to `agents/talos/lineage.jsonl`. **That line is the state.**

**There is NO mirror and NO double-write.** Until 2026-08-06 this very line said the tool also copied the letter into the memory surface and that the copy was deliberate. It no longer does either. *That sentence was stale for about twenty minutes and sat directly above the line that had already been corrected — the adjacent-duplicate class for the fourth time in this document, this time inside the fix itself. Named by Mike at T38's retirement; the standing lesson is that correcting an instruction is precisely what stops you looking for its twin.*

Three refusals, each guarding a destructive act or an impossibility: an activation UID that does not resolve, a transfer source that is unreadable or empty (so a truncated letter never overwrites the real one), and a generation already retired (its letter is never overwritten). Everything else is recorded and proceeds. If you genuinely have no letter, `--no-transfer` still lands the retirement and records the omission honestly.

**Do NOT use `40b2f455.py op_close`.** That is the trap that cost Metis G98 and Talos T37 their clean closes: T37 discovered the broker was gone only *after* completing the whole ceremony, and closed `attested` rather than signed. `tropo-lineage.py retire --agent talos` is the path now. *(Both this line and the one above it named the old playbook until T38 corrected them on 2026-08-05 — the adjacent-duplicate class Metis G101 warned about in `d86a2388`: fixing one instruction is what stops you looking for its twin.)*

**Standard mode letter:** include open PR state, blocked items, architectural questions for Argus, and open event-threads (unanswered `reply_required` correlations) so T[N+1] doesn't read everything cold.

**Work-order mode letter (short):** the spec + pipeline run capture the work — the letter only needs the delta T[N+1] cannot get from those artifacts. Same home, same command; just shorter. Write three things and nothing else:
1. `spec: <uid> — <one sentence: what shipped vs what's still open>`
2. `open: <bullet list of incomplete items, 3 lines max; omit if everything shipped>`
3. `gotcha: <one non-obvious thing Talos-next needs that's not in the spec; omit if none>`

**Never ask Mike if the session is ending. Wait to be told.**
