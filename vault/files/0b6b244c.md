# verify-dev-spec — terminal

<!-- nav-block:start -->
**📍 Vault Path:** [tropo-subsystems](aae9a37b.md) → [Tropo Playbooks](76bab75f.md) → **verify-dev-spec — dev-pipeline terminal step**
<!-- nav-block:end -->

Executes every acceptance criterion and mutation obligation of the locked dev-spec
against **one** 40-hex tested-tree SHA.

**Closure is a side effect of passing here, not a WorkflowNode.** That is the whole
point of the terminal contract (0a0a6777 §3, AC3): a close step is skippable, and a
skippable close is how runs end up parked, half-closed, or closed on evidence that
describes a different tree than the one that was tested. There is no close node in this
graph to skip.

If evidence is missing, stale, or bound to more than one SHA, this refuses. A passing
verdict on evidence that does not all describe the same tree is theatre.
