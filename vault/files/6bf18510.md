## What this is

The one release profile v1.92 ships (dev-spec [`5b608d28`](5b608d28.md), Stream 1
AC5), under the type drafted by Argus at [`vault/capsules/tropo-release-profile.capsule.md`](../capsules/tropo-release-profile.capsule.md)
(uid `654f3a90`, `status: draft` — Mike locks new types). It binds the release
machine's three generic slots to the real twelve declared leaves of the
release-pipeline ([`634913c2`](634913c2.md)) for the `tropo` product: 7
deterministic (`kind: tool`) and 5 judgment (`kind: playbook`) — the split
independently measured by both Talos T51 and Argus A156 before AC2's
contract (`lib/release_bindings.py`) was declared.

## Provisional entries

The `entry` values for `kind: tool` steps name the acting script, not a
verified internal callable — `tropo-build-release.py` alone carries ~28
step functions across a numbering scheme this profile does not attempt to
resolve. AC2 (Argus A156, Stream 1) is where each tool declares its own
`PIPELINE_BINDINGS` against `lib.release_bindings.ExecutorBinding`; once
that lands, the equivalent bindings on this profile should be checked
against it and tightened to the exact callable where one exists. This is
the honest partial-coverage state the capsule's own §4 names: *"a type that
refuses to load an incomplete profile cannot be used to report how
incomplete it is."*

`bc6b17ec` (external-test) and `37996741` (notify-triggered-pipeline-owners)
name no *dedicated* governed procedure today. They now bind to their OWN leaf
entry — which resolves, and whose body carries the numbered steps the executor
performs — rather than to a descriptive string. The instinct behind the earlier
value was right and this keeps it: a fabricated UID that resolves to nothing
would read as coverage this profile does
not have.

**Correction (2026-08-25, talos-t51):** `c6b61fb9` (cold-boot-walk) originally
copied `release_bindings.py`'s own worked example verbatim — `entry: e2c7d185`
(Agent Retirement), `executor: human`. Argus A157 caught that the retirement
playbook governs nothing in the release path and the leaf's own Flow Rules
name `6f3d2a18` (Release Cold-Boot Walk, orchestrator-run with Vela
ratifying) instead; he fixed the example, and this profile's copy is fixed
here to match. Left in the record rather than silently amended: a governed
file is read by whoever comes next, and the "why" survives better as a
correction than as a diff nobody narrates.
