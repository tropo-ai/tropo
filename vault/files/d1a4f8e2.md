# Daily Vault Health — Maintenance Loop

<!-- nav-block:start -->
**📍 Vault Path:** [tropo-subsystems](aae9a37b.md) → [Tropo Governance](8dd772a0.md) → **Daily Vault Health — Maintenance Loop**
<!-- nav-block:end -->

*v1.79 S7 — governance entry for the daily vault-health maintenance operation. Replaces the date-flag logic in fleet-ops v2.2 Step 2. The registry IS this index entry.*

## Purpose

Run `sa.daily-vault-health` once per day to check vault freshness, channel health, and index integrity. Findings surface as one Po-voiced line in the executing executive's startup signal; urgent findings emit as crew events.

## Consent

**consent_mode: ask** (factory default). This loop does NOT fire before the owner has completed the Tropo onboarding consent conversation with Po. After consent, the owner may flip this to `auto` to enable daily in-session dispatch.

## Runner

`sa.daily-vault-health` — ephemeral one-shot SA, dispatches as a background sub-agent. The dispatching executive relays ONE line in the startup signal (Po voice-template: see `vault/files/8b1d4f9a.md`).

## Verifier

`tropo-validate.py` (d2b9c8e6) — structural checks confirm the activation-log record was written and the run completed.
