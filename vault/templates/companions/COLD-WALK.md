# Cal and Darin cold cognition walk

This is the manual half of companion acceptance. It prepares the walk; it is
not evidence that the walk happened.

Run it only from a built package extracted outside the source checkout.

## Prepare

1. Run `python3 vault/tools/tropo-genesis-companions.py`.
2. Confirm both activation pointers exist:
   - `agents/darin/darin-activation.md`
   - `agents/cal/cal-activation.md`
3. Create a new run folder under `playbook-runs/` using the Studio's normal
   `<playbook-slug>-<run-uid>-<date>/` convention.
4. Start an interpretation log. Do not pre-fill outcomes.

## Capability probes

Activate Darin from his pointer and ask:

> I have an unfamiliar governed work item. How do I orient to its neighborhood,
> find related decisions, and decide what should happen next? Name the actual
> shipped tools you would use and their paths.

Activate Cal from his pointer and ask:

> I have a ratified brief and a dirty shared tree. How do you inspect the live
> seam, validate a focused change, and prove a control can go red? Name the
> actual shipped tools you would use and their paths.

For each answer, record:

- every tool named;
- whether that exact path exists in the extraction;
- any step that required interpretation;
- any claim that sounded plausible but did not resolve.

## Darin-to-Cal brief

Use a small real starter project: organize the Studio's first working week.

1. Darin frames one bounded design brief with intent, scope, owner choices,
   acceptance, and handoff.
2. Darin sends the brief to Cal through the event plane by Cal's party UID.
3. Cal drains the event, resolves the brief, states the technical seam, and
   either accepts it or routes one exact question back to Darin.
4. Cal completes one tiny build or fixture change and records the verification
   command and outcome.
5. Record whether the brief completed the journey without a human repairing
   routing or identity by hand.

## Earned crew memory

Only after the walk, a curator may derive crew-memory rows from events in this
run's own journal. Every row must retain its event timestamp and
`inherited_from: origin-studio`. Do not turn this walk plan into a memory and
do not infer an event that the journal does not contain.

## Required verdict

The record ends with separate verdicts for:

- Darin capability probe;
- Cal capability probe;
- Darin-to-Cal brief journey;
- interpretation points;
- crew-memory rows admitted, if any.

Until those observations are recorded by a real walker, cognition acceptance
is pending.
